浏览器 UI

UI 布局（单页流程式）

关键设计决策

🔌 Flask API 设计
4 个端点：上传文件、开始处理、查询进度（轮询）、下载结果。简洁够用，不过度设计
📦 打包策略
PyInstaller 打包 Python + Flask + U2-Net + ffmpeg + img2webp 为一个 .app / .exe
🔄 处理管线
直接复用现有 video2webp.sh + Python 后处理脚本，验证过的管线不重写
🎯 跨平台
Mac 用 GitHub Actions macOS runner 构建 .app；Win 用 Windows runner 构建 .exe

文件结构

app/
├── main.py ← Flask 入口 + 自动打开浏览器
├── templates/index.html ← 单页 UI（含 JS 逻辑）
├── static/ ← CSS / JS
├── pipeline.py ← 处理流水线编排
├── scripts/ ← video2webp.sh + Python 后处理脚本（现有）
├── build_config.py ← PyInstaller 配置
└── bin/ ← ffmpeg、img2webp 二进制（平台区别）
